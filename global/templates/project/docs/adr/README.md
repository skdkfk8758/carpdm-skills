# ADR — 설계 결정 기록

## 규약

- 파일명 `NNNN-<slug>.md` — **4자리 번호**, 001 이 아니라 `0001`. 번호는 재사용하지 않는다.
- `0000-template.md` 는 템플릿이다. 복사해서 다음 번호로 저장한다.
- **한 결정 한 파일.** 결정이 둘이면 파일도 둘이다.
- Status 는 셋 중 하나:
  - `Proposed` — 초안. 승인 전.
  - `Accepted` — 승인됨. 현행 결정.
  - `Superseded by NNNN` — 대체됨. 본문은 **고치지 않고** 그대로 둔다.
- 이미 `Accepted` 인 ADR 의 결정을 바꾸려면 새 ADR 을 쓰고 옛 것을 `Superseded` 로 표시한다.
- **스텝 계획은 그 ADR 의 `## Steps` 절에** 적는다. 별도 계획 문서를 만들지 않는다.
  스텝당 파일 3개 이하·커밋 1개.
- 결정이 없는 작업(버그 수정·문구 변경·기계적 편집)은 ADR 을 만들지 않는다.

## 쓰는 시점

설계 결정이 나온 **직후, 구현 전**. 구현하고 나서 적는 ADR 은 기록이지 결정이 아니다.
