# Env File Discipline — .env 변경은 고지·복원·최종상태 보고

IMPORTANT: 디버깅 중 `.env*` 파일을 **말없이 수정하지 않는다**. 실측: 디버깅 과정에서 ADMAP_PROXY_TARGET 을 임의 변경 후 최종 상태를 보고하지 않아 사용자가 파일의 진짜 상태를 모르게 됨. env 파일은 git 밖(대부분 gitignore)이라 diff 로 추적 불가 — 변경이 조용하면 영구히 은폐된다.

## 규칙

1. **변경 전 고지** — `.env`, `.env.local`, `.env.dev` 등 환경 파일을 수정해야 하면 무엇을 왜 바꾸는지 먼저 말한다. 임시 디버깅 목적이면 그 사실도 명시.
2. **임시 변경은 복원** — 디버깅용 임시 변경은 검증 종료 시 원래 값으로 되돌린다. 되돌릴 수 없으면(원래 값 미기록 등) 그 사실을 보고.
3. **최종 상태 보고** — 작업 종료 시 env 파일의 최종 상태를 명시한다: "복원 완료 / X=Y 로 변경 유지(사유)" 중 하나. 침묵 금지.
4. **수정 전 원값 기록** — 변경 직전 해당 키의 현재 값을 기록(대화 내 표기)해 복원 근거를 남긴다. secret 값이면 값 자체 대신 "기존 값 존재" 로 마스킹.

## Anti-patterns

- 디버깅 중 env 값 임시 변경 → 검증 끝나고 복원·보고 없이 다음 작업 진행.
- 원값 기록 없이 덮어쓰기 — 복원 불가 상태 자초.
- 최종 보고에서 코드 변경만 나열하고 env 변경 누락 — git 밖 변경일수록 보고 의무가 크다.
